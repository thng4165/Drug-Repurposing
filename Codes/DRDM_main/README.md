# Deep learning framework with a debiasing mechanism (DRDM)
This is the PyTorch implementation of DRDM for drug repositioning associated [2]

The original code was downloaded from https://github.com/1yiw/DRDM

## Environment Requirement
- python==3.7.7
- torch==1.7.1
- scikit-learn==1.0.2

## Usage
**Original implementation:**  
  * Run main.py

**Adjusted implementation for our paper [1] (Benchmarking Heterogeneous Network-Based Methods for Drug Repurposing):**
  * Run mainDR.py

### Reference
[1] Nguyen, T. T., Pawitan, Y., Calza, S., & Vu, T. N. (2025). Benchmarking heterogeneous network-based methods for drug repurposing. npj Systems Biology and Applications.

[2] MENG, Yajie, et al. Adaptive debiasing learning for drug repositioning. Journal of Biomedical Informatics, 2025, 104843.
